# Bitnami Moodle container sources (development only)
#
# Free Hub images (bitnami/moodle) are no longer available. The Dockerfile
# fetches the Apache-2.0 build recipe from bitnami/containers at build time
# (BITNAMI_CONTAINERS_REF) and downloads components from
# downloads.bitnami.com/files/stacksmith with SHA-256 verification.
#
# Source: https://github.com/bitnami/containers/tree/main/bitnami/moodle/5.3/debian-12
# Commit: 646ff60e45ccc895d66d9d5efe830b359839c712
#
# To bump versions, update BITNAMI_CONTAINERS_REF, COMPONENTS, and the
# display LABEL / APP_VERSION. Mismatched COMPONENTS fail sha256sum -c.
#
# If stacksmith packages become unavailable, migrate to the
# moodlehq/moodle-php-apache-based approach instead.
